# 👟 Adidas Sales Dashboard

## 📌 Overview
This project is an interactive **Adidas Sales Dashboard** created to analyze sales performance across regions, product categories, and retailers.

It helps identify trends, compare performance, and support data-driven decisions.

---

## 📊 Dashboard Highlights
- Total Sales: **120M**
- Operating Profit: **47.22M**
- Units Sold: **2M**

---

## 📈 Key Insights
- West region has the highest sales contribution  
- Top retailers drive a major portion of revenue  
- Sales are evenly distributed across product categories  
- Monthly trends show fluctuations with peak sales in later months  

---

## 📂 Features
- Region-wise sales breakdown  
- Retailer performance comparison  
- Product category distribution  
- Monthly sales trend analysis  
- Filters for Gender and Sales Method  

---

## 🛠️ Tools Used
- Excel / Power BI  
- Data Cleaning  
- Data Visualization
