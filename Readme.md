# 👟 Adidas Sales Dashboard (Power BI Project)

## 📌 Project Overview

This project focuses on analyzing Adidas sales data using an interactive dashboard built in Power BI.

It helps in understanding sales performance across different regions, product categories, and retailers, and provides meaningful insights for business decision-making.

---

## 🛠️ Tools & Technologies

* Power BI
* Excel (Data Source)
* Data Cleaning & Transformation
* Data Visualization

---

## 📊 Dashboard Features

* Total Sales, Operating Profit, and Units Sold KPIs
* Region-wise Sales Analysis
* Retailer Performance Comparison
* Product Category Distribution
* Monthly Sales Trends
* Filters for Gender and Sales Method

---

## 🗂️ Dataset Description

The dataset includes:

* Sales data (Total Sales, Units Sold, Profit)
* Product categories (Apparel, Footwear, etc.)
* Retailer details
* Regional sales distribution
* Customer segmentation (Men/Women)

---

## 📈 Key Insights

* West region contributes the highest share of total sales  
* Top retailers generate significant revenue compared to others  
* Balanced sales distribution across product categories  
* Sales show growth trend in later months of the year  
* Both online and in-store sales channels contribute effectively
